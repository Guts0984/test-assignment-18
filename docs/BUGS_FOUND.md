# Bugs found by tests

| # | Bug | Found by | Fix |
|---|---|---|---|
| 1 | With Redis unreachable, closing the job publisher waited for a connection for ever, so an api copy could not shut down. | `apps/api/test/adv/limiter.adv.spec.ts` (Redis down) | The publisher drops the socket without closing queues when Redis is not ready (`packages/queue/src/publisher.ts`). |
| 2 | Under load, requests failed with 500 because the connection pools of two api copies could exceed the Postgres connection limit. | `apps/api/test/cohorts.it.spec.ts`, webhook suite | `max_connections` raised in compose; pools bounded in tests. |
| 3 | Two different response schemas used the same DTO class name (`StudentPageDto`, `SubmissionDto`), so the OpenAPI document, and the generated client, described the manager's roster with the mentor's shape. | TypeScript type check of the web app against the generated client | Names made unique; `apps/api/src/openapi-names.spec.ts` fails on any reuse. |
| 4 | The worker's `ioredis` was only a development dependency, so the pruned production image crashed on start. | Compose start of the pruned images | Moved to runtime dependencies; `scripts/check-dependencies.mjs` runs in lint. |
| 5 | Seeded ids were `md5(...)::uuid`, which are not well-formed UUIDs. The response schemas rejected every seeded row, so on a fresh `docker compose up` the catalog and every login answered 500. | Smoke test through nginx on the seeded stack; reproduced by `apps/api/test/seeded.it.spec.ts` | Seed ids are version 4 UUIDs (`packages/db/seed/ids.ts`); the seed test checks every table. |
| 6 | The compose network had no fixed subnet. On a host whose usual Docker ranges were taken, it received `192.168.0.0/20` and the bridge claimed `192.168.0.1`, the home router's address, cutting the host off from Wi-Fi. | Developer machine lost its connection while the stack was up | The subnet is pinned (`COMPOSE_SUBNET`, default `10.213.47.0/24`), and only that range is trusted as a proxy. |
| 7 | On the full data set the manager's student search took up to 4.6 s (budget 300 ms) and the twelve-month report 1.9 s (budget 1 s). | `tests/perf/budgets.x.spec.ts` | A trigger-maintained `school_students` search table, covering indexes for the report, planner settings for solid-state storage (migration `0004`). |
| 8 | No deadline reminder was sent for the last week of homework: the cohort completes when the last lesson ends, and the reminder only went to students still `paid`. | `apps/worker/test/adv/queues.adv.spec.ts` | Reminders go to `paid` and `completed` students (`packages/db/src/repo/reminder.ts`). |
